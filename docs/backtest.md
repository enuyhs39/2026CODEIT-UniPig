## 요약 지표

| 지표 | 값 | 목표 |
|---|---|---|
| 커버리지 (실제수입이 P10~P90 안에 든 비율) | 100.0% | 80% |
| 예산 붕괴율 (실제수입 < P25인 비율) | 0.0% | 25% 이하 |
| 평균 Pinball Loss | 18,116 | - |
| 조정률 추이 | 140,000원 → 138,000원 → 137,000원 (매달 "카페" 확정 시 목표와의 격차, 3회 시뮬레이션) | 감소 |

**조정률 추이 상세**: 사용자가 매달 "카페" 배분을 15만원으로 고쳐 확정한다고 가정하고 3회 반복한 결과,
AI 원안의 카페 배분이 10,000원 → 12,000원 → 13,000원으로 목표치에 점점 가까워졌다(EMA α=0.25로
천천히 수렴 — 절대 규칙 6번). 사용자가 매번 고쳐야 하는 격차가 140,000 → 138,000 → 137,000원으로
회차마다 줄어드는 것으로 "조정률이 감소하는지"를 확인했다.

실행: `npx tsx scripts/backtestDemo.ts` (수입 예측 검증), `npx tsx scripts/budgetDemo.ts` (예산+피드백 학습 검증)
